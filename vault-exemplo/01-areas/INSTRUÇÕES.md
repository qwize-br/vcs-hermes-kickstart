# Áreas (contínuas e globais)

Áreas **não terminam** — são os departamentos da sua operação. Tudo o que é recorrente e não está atrelado a um único projeto ou cliente mora aqui.

| Área | O que concentra |
|---|---|
| **Comercial** | propostas, leads, follow-ups, scripts de venda |
| **Desenvolvimento** | padrões técnicos, boilerplate, decisões de stack |
| **Operação** | rotinas semanais, cadências, checklists de entrega |
| **Financeiro** | faturamento, custos, fluxo de caixa |

Quando uma reunião gera uma decisão que vale para **todos** os projetos — ex.: "passamos a cobrar 50% na entrada" — ela fica na área correspondente, não no projeto de um cliente só.
